# Preguntas
## 1 ¿Qué diferencia hay entre una variable con un string y un objeto?
Que el objeto es una coleccion de pares clave/valor, y una variable es un valor individual.
## 2 ¿Qué significa activo: true en el objeto alumno? ¿Qué tipo de dato es?
Sin saber el contexto que rodea al objeto, asumo que quiere decir que el alumno está dado de alta en el curso. Es un dato booleano.
## 3 ¿Por qué la función recibe alumno como parámetro en lugar de usar la variable directamente?
Por diferenciar entre el ambito interno y externo de la funcion.
