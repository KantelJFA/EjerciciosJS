# Preguntas
## 1 ¿Para qué sirve export en calculadora.js?
Para que la funcion que contiene sea visible en otros archivos.
## 2 ¿Qué pasaría si quitamos type="module" del script en el HTML?
Que el navegador no podría acceder al script.
## 3 ¿Por qué calculadora.js no usa document.querySelector?
Porque no necesita buscar ningun elemento del arbol DOM.
## 4 ¿Cómo harías que el precio base se lea de un \<input\> del usuario?
Sustituiría el valor del precio base por un imput, movería precioBase al evento y haría que  lea el valor introducido en el imput. El resto seguiría igual.
